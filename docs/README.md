# કાર્ય મેટ્રિક્સ — ઇન્સ્ટૉલ થઈ શકે એવી એપ (PWA)

રોજના ટાસ્ક ઉમેરો; એ તારીખ અને શીખેલા શબ્દો પરથી Eisenhower મેટ્રિક્સનાં ચાર ખાનામાં
(Do now / Schedule / Delegate / Drop) જાતે ગોઠવાઈ જાય.

આ ફોલ્ડર એક સંપૂર્ણ સ્થિર (static) વેબ-એપ છે. કોઈ સર્વર, કોઈ લૉગિન, કોઈ બૅકએન્ડ નહીં.
બધો ડેટા વાપરનારના બ્રાઉઝરના `localStorage` માં જ રહે છે.

---

## ૧. વેબસાઇટ ચાલુ કરવી (એક વખતનું કામ)

GitHub પર: **Settings → Pages**

- **Source:** `Deploy from a branch`
- **Branch:** ડિફૉલ્ટ બ્રાન્ચ, અને **folder:** `/docs`
- **Save**

એકાદ મિનિટમાં સાઇટ અહીં ચાલુ થશે:

```
https://aadarsh77.github.io/Claude/
```

CLI થી એ જ કામ:

```bash
gh api -X POST repos/aadarsh77/Claude/pages \
  -f 'source[branch]=<default-branch>' -f 'source[path]=/docs'
```

## ૨. ફોનમાં ઇન્સ્ટૉલ કરવું

**Android (Chrome):** ઉપરની લિન્ક ખોલો → હેડરમાં **⤓** બટન દબાવો,
અથવા Chrome ના ⋮ મેનુમાંથી **Install app** / **Add to Home screen**.

**iPhone (Safari):** લિન્ક Safari માં જ ખોલો (Chrome માં નહીં) → નીચે **Share (↑)** →
**Add to Home Screen**. એપ પહેલી વાર ખૂલે ત્યારે આ સૂચના સ્ક્રીન પર પણ દેખાશે.

ઇન્સ્ટૉલ થયા પછી એપ પોતાની વિન્ડોમાં, બ્રાઉઝરના એડ્રેસ-બાર વગર ખૂલે છે,
અને **ઇન્ટરનેટ વગર પણ ચાલે છે** (service worker આખી એપ ફોનમાં કૅશ કરી રાખે છે).

## ૩. ડેટા ક્યાં રહે છે

ડિફૉલ્ટમાં **ફક્ત એ જ ફોનમાં** (`localStorage`). કોઈ સર્વર નહીં, કોઈ લૉગિન નહીં, કોઈ સિંક નહીં.

બ્રાઉઝરનો ડેટા સાફ કરશો કે એપ અનઇન્સ્ટૉલ કરશો તો ટાસ્ક જતા રહેશે. એટલે મહિને એકાદ વાર
મેનુ (⋯) → **બૅકઅપ ફાઇલ ઉતારો (.json)**. બીજા ફોનમાં લઈ જવા ત્યાં
મેનુ → **બૅકઅપ ફાઇલ ચઢાવો**.

## ૪. સિંક ચાલુ કરવું (મરજિયાત)

સિંક ચાલુ કરશો તો બધા ડિવાઇસ પર એક જ યાદી રહેશે, અને **ઑફલાઇન પણ ચાલશે** —
બદલાવ ફોનમાં સચવાય અને નેટ આવે ત્યારે જાતે ચઢી જાય.

> **લૉગિન ટાળી શકાતું નથી.** સાઇટ જાહેર છે, એટલે anon key પણ જાહેર કોડમાં જ રહે.
> ઓળખ વગર લિન્ક જાણનાર કોઈ પણ તમારી યાદી વાંચી-બદલી શકે. લૉગિન **ડિવાઇસદીઠ એક જ વાર**
> કરવાનું રહેશે, પછી મહિનાઓ સુધી ટકશે.

**પગલાં:**

1. [supabase.com](https://supabase.com) પર ફ્રી ખાતું ખોલો → **New project**.
2. પ્રોજેક્ટમાં **SQL Editor** ખોલો → આ રિપોની `docs/schema.sql` આખી કૉપી-પેસ્ટ કરીને **Run**.
   (આ ટેબલ બનાવે છે અને Row Level Security ચાલુ કરે છે. આ પગલું છોડશો નહીં.)
3. **Project Settings → Data API** માંથી **Project URL** અને **anon public key** કૉપી કરો.
4. `docs/config.js` માં બંને ભરો, કમિટ કરો:

   ```js
   window.KMX_CONFIG = {
     SUPABASE_URL: "https://xxxxxxxx.supabase.co",
     SUPABASE_ANON_KEY: "eyJhbGciOi..."
   };
   ```

5. `docs/sw.js` માં `CACHE` નું નામ બદલો (`karya-matrix-v2` → `v3`), નહીં તો ફોન પર જૂની
   `config.js` જ ચાલતી રહી શકે.
6. એપમાં મેનુ (⋯) → **સિંક અને લૉગિન** → ઈ-મેલ લખો → **કોડ મોકલો** → ઈ-મેલમાં આવેલો
   ૬-અંકનો કોડ નાખો. દરેક ડિવાઇસ પર એક જ વાર, એક જ ઈ-મેલથી.
7. લૉગિન થયા પછી Supabase માં **Authentication → Sign In / Providers** માં
   **"Allow new users to sign up" બંધ** કરી દો, જેથી બીજું કોઈ ખાતું ન ખોલી શકે.

**સિંક કેવી રીતે વર્તે છે**

| | |
|---|---|
| ક્યારે ચાલે | એપ ખૂલે, બદલાવ પછી ~૨.૫ સેકન્ડે, સ્ક્રીન પાછી આવે, નેટ પાછું આવે |
| ઑફલાઇન | બધું ચાલે; બદલાવ "બાકી" ગણાય અને નેટ આવે ત્યારે ચઢે |
| બે ડિવાઇસે એક જ ટાસ્ક બદલ્યું | પાછળનો બદલાવ જીતે (`updated` સમય પ્રમાણે) |
| કાઢી નાખેલું ટાસ્ક | ૬૦ દિવસ સુધી tombstone તરીકે રહે, જેથી કાઢ્યાની ખબર બીજા ફોનને પહોંચે |
| શીખેલા શબ્દો | આખી યાદી એક સાથે, પાછળનો બદલાવ જીતે |
| લાઇબ્રેરી | કોઈ નહીં — સીધા `fetch` થી Supabase નું REST API, એટલે ઑફલાઇન કંઈ બહારથી લાવવું ન પડે |

ફ્રી Supabase પ્રોજેક્ટ ૭ દિવસ સાવ ન વપરાય તો થંભી જાય છે; રોજ વાપરશો તો વાંધો નહીં.
લૉગિન ટોકન ફોનના `localStorage` માં રહે છે — સહિયારા ફોન પર એપ ન રાખવી.

## ૫. વર્ગીકરણ કેવી રીતે થાય

**તાકીદ (Urgent)** — નક્કી નિયમોથી, અનુમાનથી નહીં:

| સ્થિતિ | પરિણામ |
|---|---|
| તારીખ વીતી ગઈ / આજ / કાલ | Urgent |
| તારીખ ૪ કે વધુ દિવસ દૂર | Not urgent |
| તારીખ ૨–૩ દિવસ દૂર | શીખેલા શબ્દો નક્કી કરે |
| તારીખ નથી, પણ લખાણમાં `આજે`, `કાલે`, `10:00`, `urgent` | Urgent |
| બીજું કંઈ નહીં | Not urgent |

**મહત્ત્વ (Important)** — શબ્દો પરથી, Naive-Bayes જેવા log-odds સ્કોરથી.
શરૂઆતની શબ્દ-યાદી (૫૫ શબ્દ) માલિકની પોતાની નોટબુકનાં
૧૭, ૧૮, ૨૧ અને ૨૨ સપ્ટેમ્બર ૨૦૨૬નાં ચાર હાથે દોરેલાં મેટ્રિક્સ પાનાંમાંથી લીધી છે —
જુઓ `app.js` માં `SEED_LEX`.

કોઈ પુરાવો ન મળે તો ડિફૉલ્ટ **Important + Not urgent = Schedule**,
જેથી અજાણ્યું ટાસ્ક ચૂપચાપ Drop માં ન જાય.

**શીખવું** — કાર્ડ પરનું `Imp` કે `Urg` બટન દબાવો (કે કાર્ડ બીજા ખાનામાં ખેંચો) એટલે
એ ટાસ્કના શબ્દોના ગુણ બદલાય. જૂનો ગુણ બાદ થાય અને નવો ઉમેરાય, એટલે આગળ-પાછળ
ફેરવવાથી ગણતરી બગડતી નથી. ખોટું શીખેલો શબ્દ "એપ શું શીખી છે" પેનલમાંથી × દબાવીને ભુલાવી શકાય.

ગુજરાતીમાં પ્રત્યય લાગે છે (પુસ્તક / પુસ્તકો / પુસ્તકોની), એટલે શબ્દ સીધો ન મળે તો
સૌથી લાંબો સામાન્ય ઉપસર્ગ શોધાય છે. ટોકનાઇઝર માત્રા અને અનુસ્વાર (`\p{M}`) તથા
ZWJ/ZWNJ સાચવે છે — નહીં તો "કબાટ" તૂટીને "કબ ટ" થઈ જાય.

## ૬. ફાઇલો

```
docs/
├── index.html              એક જ પાનું
├── styles.css              ટોકન-આધારિત થીમ, લાઇટ + ડાર્ક
├── app.js                  વર્ગીકરણ, શીખવું, સ્ટોરેજ, UI
├── config.js               Supabase URL + anon key (ખાલી = સિંક બંધ)
├── sync.js                 ઑફલાઇન-ફર્સ્ટ સિંક (લાઇબ્રેરી વગર, સીધું REST)
├── schema.sql              Supabase ટેબલ + Row Level Security
├── manifest.webmanifest    PWA મેનિફેસ્ટ
├── sw.js                   ઑફલાઇન કૅશ (બદલાવ કરો તો CACHE નું નામ બદલવું)
└── icons/                  192, 512, maskable 512, apple-touch 180
```

વેબ-ફૉન્ટ વપરાતા નથી — સિસ્ટમ ફૉન્ટ જ, જેથી ઑફલાઇન પણ ગુજરાતી બરાબર દેખાય.

`sw.js` માં `CACHE` નું નામ બદલ્યા વગર કોઈ ફાઇલ બદલશો તો ફોન પર જૂની નકલ જ ચાલતી રહેશે.
